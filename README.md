# Adarsh Subrahmannyan P — Portfolio

Minimal dark editorial portfolio inspired by the reference style supplied by Adarsh.

## Run
npm install
npm run dev

Then open http://localhost:3000

## Edit
- `app/page.tsx` — content, projects, links, sections.
- `app/globals.css` — visual system and responsive layout.
- `public/adarsh-cutout.png` — edited portrait from the supplied photo.
- Add `public/resume.pdf` when the resume is ready and point the resume CTA to it.
